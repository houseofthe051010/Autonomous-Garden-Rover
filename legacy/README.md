# Legacy and Commissioning Material

This directory preserves validated earlier hosts, test programs, and superseded
firmware. It is not the primary rover implementation and is not required to
build `firmware/esp32-p4`.

- [`raspberry-pi/`](raspberry-pi/README.md): Raspberry Pi 5 multi-UART host and
  standalone device clients.
- [`prototypes/`](prototypes/README.md): ESP32/ESP32-P4 commissioning tools and
  older GD32 firmware.

Legacy documentation may describe older pin assignments or deployed hardware.
Use active firmware READMEs for new builds.
