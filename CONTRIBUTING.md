# Contributing


## Scope

If you plan to build this project yourself, you don't have to copy everything. You can carve your own path, and I have left the code for the raspberry pi 5 (ROS 2) host if you want to go the linux route, but currently the newest version of my rover uses a esp32 P4 as the brain as its much cheaper capable enough.

## Development

1. Open an issue for changes you make.
2. There are many sub-systems to make changes in. 
3. You can modify the drivetrain, the frame, the mower, the electronics, or add other features
4. Make sure to document everything you change
